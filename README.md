# Campus Fund

Flutter starter application for a student funding workflow.

## Run in VS Code

1. Install Flutter SDK and the Flutter extension in VS Code.
2. Open this folder in VS Code.
3. Run:
   flutter pub get
4. Start an Android emulator or connect an Android phone with USB debugging enabled.
5. Run:
   flutter run

## Current demo flow

Splash -> Mobile Login -> OTP -> Student Dashboard -> Apply for Funding -> Review -> Submitted -> Application Status -> Repayment -> Payment Success.

This is a UI/demo starter. Authentication, backend APIs, KYC verification, secure document storage, real payment gateway integration, notifications, and production lending/compliance controls are not connected yet.
